## My Task Manager
The website lets the user add tasks with 3 levels of priority (low, medium, high) and then keeps the tasks in a list. Once the tasks are added they are in a list with different colors depending on priority and you can complete them or delete them from the list.
## How To Use
First - The user types in a task they have to do
Second - The user can select the priority of the task
Third - The user can click Add Task to add it to the list
Fourth - They can click the Complete button to signify the task is Done
Fifth - They can click the Delete button to remove the task from the list
